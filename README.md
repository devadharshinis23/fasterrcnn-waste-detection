# fasterrcnn-waste-detection
Faster R-CNN (ResNet50-FPN-v2) fine-tuned on TACO for multi-object litter detection across 10 classes. Full Colab pipeline: Flickr image download, COCO annotation handling, training, and COCO mAP evaluation. Current run: AP@[.5:.95]=0.019 — early-stage baseline, documented honestly with next steps for improvement.
